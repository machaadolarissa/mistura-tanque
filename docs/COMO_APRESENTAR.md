# Como apresentar (3 minutos)

## Abertura
“Produtor mistura produto A com B no tanque e às vezes estraga a calda. Fizemos um site que a loja de insumos usa no balcão para checar a mistura em segundos.”

## Demo
1. `/` → Biológico + Cobre → **NÃO misture**.
2. Glifosato + 2,4-D → **cuidado**.
3. `npm run sensor` + `/agua` → mostrar pH e média (DSP).
4. `/historico` → mostrar que a loja registra as dúvidas.

## Técnico
Web Node, regras em arquivo JS, IoT simulado por HTTP, testes e CI.

## Negócio
Assinatura mensal; piloto na loja parceira; depois sensor de pH real.

## Fecho
“Simples, diferente de portal de pedido, e útil no dia a dia da loja.”
